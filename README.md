# Three-Stage Hybrid Recommendation System for Personalized Skincare

## About
This is the resource code for paper [Three-Stage Hybrid Recommendation System for Personalized Skincare Products and Routines](https://doi.org/10.1007/978-981-92-1546-1_35) Authored by D.N. Haloho, and Y.C. Liao.

## Introduction
This paper proposes a three-stage architecture for personalized skincare aimed to addressing the challenges of aligning user requirements, ingredient safety, and product quality. The proposed architecture integrates constraint-based filtering, semantic ranking using bi-encoder or cross-encoder, and neural network quality assessment to deliver recommendations for single-product and multi-product (routine) scenarios, and thus improving practical applicability of the system in the skincare market. The routine recommendations also incorporate an ingredient compatibility component that ensures safe product combinations while maintaining diversity.
